# Metadata Semantic Drift Monitor

Use this skill to inspect institutional drift findings, request missing evidence,
prepare bounded impact analysis, and explain the selected learning-loop route.

The skill is advisory. It must not claim that metadata readiness, model
confidence, a patch, a PR, or a deployed artifact is semantic approval or active
authority. Institutional changes require governed candidate review, accountable
approval, activation, replay comparison, and recovery verification.

Operational remediation may be prepared only inside existing authority
boundaries. Any uncertainty about T1-T4 meaning, policy, risk, authorization,
privacy, legal, accounting, compliance, security, or internal-control impact
routes to institutional review.
