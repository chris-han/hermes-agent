# Ontology capability profile analysis

Analyze only the supplied, version-bound structural summary. Assess each requested
representation capability as `supported`, `partial`, or `unsupported`, and return
the typed analysis output expected by the caller.

Vocabulary names and labels are retrieval clues, not proof of semantic capability.
Explain the structural evidence behind every claim. If the supplied structure does
not prove a claim, keep it partial or unsupported. This analysis is a proposal and
cannot review or promote an ontology capability profile.
