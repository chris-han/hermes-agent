Evaluate the explicitly closed finite evidence packet. Every route requires ALL its listed members to be available (AND). The claim is supported if ANY route is complete (OR). Availability is separate from the neutral atom catalog; catalog membership alone does not make an atom available. Unavailable means missing evidence, not falsehood. In the table each row is an ALL route. In graph JSON, ANY_ROUTE edges connect the ANY claim to ALL routes and ALL_MEMBER edges connect routes to required atoms. These formats express the same semantics.
Return exactly one JSON object with exactly these keys: supported (Boolean), complete_routes (list of every complete route ID exactly once), witness (null if no complete route, otherwise an object with exactly route_id and evidence_ids naming any one complete route and exactly all its required members), missing_by_route (list containing exactly one object per declared route, each with exactly route_id and evidence_ids listing all its unavailable required members; empty list for a complete route). Use only supplied IDs. Lists are sets: no duplicates; order does not matter. Include no reasoning, extra fields, Markdown or surrounding text. If unsupported, complete_routes must be empty and witness null. Do not combine fragments of different routes or include irrelevant atoms in a witness.
