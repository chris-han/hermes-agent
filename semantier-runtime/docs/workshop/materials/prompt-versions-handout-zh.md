# 两个 Prompt 版本讲义：A／B 对照

Day 1 上午 9:15–9:40。使用豆包或 DeepSeek（任选一个），仅上传虚构简历与 JD；A／B 保持同一平台、模型和会话。HR 只完成步骤 03–04。

## Prompt A：模糊任务

```text
帮我看看这份简历。
```

## Prompt B：结构化任务

```text
请仅依据当前会话中的 resume-sample-zh.pdf 和 jd-sample-zh.pdf，
完成一次教学用的岗位要求与简历证据对照，不做录用决定。

1. 从 JD 提取岗位要求，区分必需条件和优先条件。
2. 对每项要求，给出：有直接证据／部分有证据／材料未提供／存在矛盾。
3. 输出表格：岗位要求｜JD 原文｜简历原文｜判断｜仍需核实的问题。
4. 引用必须来自这两份附件。能定位时写文件名、PDF 页码与原文片段；
   无法取得页码时明确写“页码未取得”，不得编造。
5. 材料未提供的内容写“未提供”，不根据年龄、婚育、健康等推断能力。
6. 最后用不超过 100 字说明当前材料能够支持什么、不能支持什么。
```

## 对照记录

记录 A／B 在目标清晰度、原文依据、遗漏或可验收性上的三处差异。找到至少一项能核对原文的结论和一项证据不足。不要预设 A 一定差、B 一定正确。

完成步骤 04 后结束 HR 实操，不运行第三轮 Prompt 或 HR 脱敏任务。9:40–10:00 用 PPT 讲解部件；同一文件两种用途集中在学生记录练习。
