## 当前资料与原始样本
简历、JD、学生记录和经营简报是虚构教学样本。指定发票是真实提供的原始文件，不纳入虚构材料自动播种。教学报销政策不代表发票公司制度。

学生上传样本位于 student/ 子目录，PDF 与 Markdown 均只保留业务正文，不含讲师备注、模拟培训声明、课时安排或练习提示。虚构性质仅在本索引与资料包说明中声明，不混入上传正文。讲师原稿单独保留，不分发。指定发票与教学政策来源保持不变。

清理后的样本具有新的文件哈希。可选财务固定标注仅适用于讲师指定并实际绑定的版本；本包清洁副本可用于阅读及自选分析，不直接沿用原件的标注或页码映射。

## 学习范围
9:40–10:00 和 10:10–10:20 只用 PPT 讲解，不执行 Memory 保存、跨会话验证、知识库搜索或独立 Governance Demo。HR 到步骤 04 结束。学生记录只比较用途与保护建议，不做涉密封面阻断亲试。上午不做报销批准、拒绝、付款、过账或受限查看／复制租约。

财务主入口为讲师部署的“报销政策审阅”，路径 /ontology-workbench2?taskIntent=expense-reimbursement。政策来源、文件解析和图谱以实际应用可用状态为准；没有接通的功能如实记录，不以人工打开原件代替自动定位验收。

## 提交与反馈
课堂自选文件只需一项信息发现、一项保护建议或不确定性、一项待确认缺口。课后作业按议程八项要求提交，讲师在五个工作日内书面反馈。来源未知时明确标记，不将机器建议称为正式定密或合规认证。
