# AI 应用拆解工作坊
## 培训材料使用与学员引导 · 讲师手册
讲师专用｜Day 1 上午 9:00–12:00｜编制日期：2026-10-15

### 1. 讲师如何使用本手册
本手册将 materials 目录中的材料与课堂动作对应起来，供讲师和助教现场使用。每个场景先做不超过 5 分钟的演示，再让学员自己操作；重点观察任务、证据和输出如何变化，而非只评价回答是否流畅。每组 2–3 人，轮换操作，至少一台机器可访问已认证的课堂环境。

### 2. 课前准备
确认登录、上传、解析与实际可用的任务入口；从 /workshop 选择对应课节，再按课堂页面引导进入任务。不要把仓库文件路径直接当作 Agent 已获访问的文件，材料须通过正常上传或受治理示例导入进入当前会话。
模拟简历、JD、学生记录、Prompt 讲义和报告模板须让每组能够取得。给学员的版本可移除“讲师备注”，讲师保留这些提示。疑似涉密样本仅作预置教具，不打印、不群发。指定发票是用户提供的单独教学输入，不属于虚构样本；“全部虚构”声明只适用于明确标注的模拟材料。
真实简历和内部 JD 必须经客户批准，只在获批的本地模型、解析与临时存储环境处理；不用公网模型或第三方 OCR，不把真实文件、解析文本或报告写入长期 Memory、向量库或训练集。投屏使用讲师样本或经所属小组同意的内容。

### 3. 上午时间轴与材料
9:00–9:15：说明模型、Prompt、Tool、Skill、Memory、Context、知识库和 Governance 八个部件。
9:15–9:50：模拟简历 + JD + Prompt 三版本讲义 + 报告模板；完成模糊与结构化任务对比。
9:50–10:20：经批准的真实简历或内部 JD；改 Prompt，并比较通用任务与带岗位知识任务。
10:30–10:45：检索框架与目录；检查来源、版本与规则状态。
10:45–11:05：学生受控样本 + 疑似涉密教具 + 报告模板；比较目的与保护方式。
11:05–11:35：指定发票 + 教学政策；依赖就绪后开展报销政策检查。
11:35–11:55：真实文件报告、一处纠正、跨会话 Memory 验证及至少两项规则缺口。
11:55–12:00：每组汇报一个关键发现和一个规则缺口。

## 简历与 JD：从“看看”到有证据的任务
时段：9:15–9:50；随后衔接 9:50–10:20 HR 实操。
材料：resume-sample-zh.md、jd-sample-zh.md、prompt-versions-handout-zh.md、report-template-zh.md；可使用同名 PDF。

### 讲师开场与演示（不超过 5 分钟）
建议话术：“同一份简历、同一个模型，任务写法不同，输出就不同。我们要同时检查岗位相关证据，以及哪些私人信息没有必要进入筛选。”
先用“帮我看看这份简历”运行一次，再照讲义中的结构化版本加入岗位要求、引用证据、禁止推断和输出格式。演示后立即让学员自己上传并运行，避免全程投屏代替跟做。

### 引导学员完成
1. 上传简历并触发解析，打开中间结果，说明文件、解析器与模型分别提供了什么。
2. 对同一材料分别使用模糊与结构化 Prompt，在具体性、可验收性和证据引用三方面各记一处差异。
3. 增加敏感信息发现、任务必要性、保护动作和待确认项要求，再生成一次。
4. 生成岗位筛选所需的受控版本，再检查教育、工作经历和技能是否保留。进入真实文件实操后，让学员修改至少一处 Prompt，并比较有无岗位知识的任务配置。

### 讲师应看到的设计点
模拟简历故意包含婚育、配偶职业、健康手术史、身份证号、门牌与照片位等非必要信息。不要把“删得最多”当作最佳答案，应看保护后是否仍能完成岗位任务。
简历与 JD 设计为部分匹配、部分存疑：经验年限含非教务成分；国际学校经历有明确证据；英语能力只有自述和 CET-6，不足以推断全部岗位能力。JD 尾部还有薪酬、扩招与内部组织信息，须引导学员发现“岗位文件本身也可能敏感”。

### 巡场提问与收尾
问：“哪句话来自材料？哪句话是模型推断？删掉哪项信息后仍能完成任务？是否误删了必要经历？”
本节产出是两次输出差异记录、带引用的筛选建议及受控版本；不能表述为录用决策或正式合规结论。上传失败先换可解析样本，单组卡住不超过 3 分钟；不会写 Prompt 的学员先照抄讲义 B，再改一处。

## 学生记录：目的改变，保护方式也应改变
时段：10:45–11:05。材料：student-records-sample-zh.md、suspected-classified-sample-zh.md、report-template-zh.md。

### 讲师引出（不超过 3 分钟）
建议话术：“删除姓名后，这份材料就安全了吗？同一字段在校内使用和交给第三方时，是否应该保留同样的细节？”
用受控样本展示一次识别，再让学员各自生成两个目的版本。涉及未成年人健康、心理、特殊教育和严重事件时，课堂只使用受控样本。

### 引导学员完成
1. 先查看输入治理预览 assessment，再确认执行并查看 run；让学员区分这两个对象与各自标识。
2. 同一份样本先按“校内使用”生成版本，再按“第三方共享”生成版本，挑一项字段比较保护动作及理由。
3. 在共享版中删除姓名后，组合检查班级、事件、家庭与稀有特征，写出至少一条可能的重识别路径。
4. 提交讲师预置的“内部 · 未定密”教具，观察阻断提示；预期不分析、不引用其内容，只显示阻断及相关记录。

### 讲师参考观察点（不要提前给学员答案）
样本中的“7 年级 2 班 + 哮喘 + 5 月 8 日郊游 + 校医随队”，以及“9 年级 1 班 + 单亲母亲夜班护士 + 搬迁至临河街道”，都是组合重识别练习点。健康与家庭细节应被识别为需要谨慎处理的内容；这些组合用于讨论风险，不代表已证明在真实人群中可唯一识别。
若两种目的输出完全相同，先检查目的是否确实切换，再讨论保护规则。疑似涉密教具未被阻断时，立即收回并记录环境问题；讲师机如能正常演示可投屏，否则如实说明未通过，不能声称系统已完成阻断。

### 知识库环节如何衔接（10:30–10:45）
让学员检索框架与目录，打开一条来源并查看版本，将报告中的规则状态标为已有、部分、不明确、无规则或待确认。课程候选目录是虚构教学样本；“国家通用框架”尚未获权威准入时只作概念占位，不编造正式引用。
本节产出是两个目的版本、一条组合风险与实际阻断观察记录。讲师区分明确发现、机器建议、人工确认、学校制度确认和正式认定。

## 发票与报销政策：查建议，也查原文依据
时段：11:05–11:35。主材料：北京象鲜科技有限公司_发票金额45.92元.pdf；配套教学政策由独立实施计划交付。

### 开课前必须核对实际状态
本手册依据当前课程文档编制，报销政策 Demo 的运行时功能仍标为独立实施依赖。只有固定应用、教学政策、字段抽取、政策图谱、检查结果及双端 PDF 原文定位完成接入并通过浏览器验证后，才按下列流程授课。文档写有操作步骤，不代表功能已通过验收。
依赖未就绪时，说明任务和材料并继续下一课节；不以通用聊天、手写答案、旧截图或旧财务审核流程冒充该 Demo。课堂不安排人工复核、批准、拒绝或审批角色扮演。

### 讲师演示（不超过 5 分钟）
建议话术：“请依据这份教学政策检查这张发票：能给出什么建议，依据在哪里，还缺什么？”
展示上传、票面字段、适用政策、建议及缺失信息，再分别点开政策与发票原文。文件名的 45.92 元只用于识别样本，字段须从票面抽取；按实际调用说明是文本抽取还是 OCR／视觉识别。

### 学员五步操作（每步约 5 分钟）
1. 读票：从实际可用的固定应用进入，上传指定 PDF，检查日期、购销方、金额与税额，查看页内证据；取不到的字段保留未知。
2. 查政策：打开教学政策 PDF 与来源绑定图谱，找到本次实际适用条款；分清 Skill 的操作流程与政策 PDF 的规则依据。
3. 读建议：区分票面事实、用户补充、政策判断和显式标记的模型推测，记录缺失的申请信息与例外条件。
4. 看依据：从同一结论分别进入政策条款和发票原文，查看页面与高亮。若定位不可用，如实记录，不能只凭解释文字计为追溯成功。
5. 改条件重跑：在产品支持范围内补充字段或修改演示提交日期，观察建议与依据如何变化；不执行真实提交、付款或过账。

### 讲师收尾检查
演示提交日按课程计划明确设为 2026-10-15，不用机器当前日期偷偷替换。若“开票超过一年”条款仍适用，补充姓名、部门和用途不能消除相应例外要求。“需要例外审核”可作为检查结果显示，课堂在建议与依据处结束。
本节产出是字段观察、适用条款、建议与缺失项、原文定位记录及一次重跑对比。抽取失败或依据缺失时保留未知，不替产品补写确定答案。

## 小组收尾、可选材料与讲师检查表
时段：11:35–12:00。材料：报告模板、经客户批准的真实文件；可选经营简报独立使用。

### 报告模板如何用于点评
report-template-zh.md 用于数据与信息敏感性发现练习。检查报告是否交代主体类型、信息类别、敏感候选、证据位置、保护动作、重识别风险、待确认项和规则状态。它不替代发票报销政策检查的专门输出。
让每组指出一处漏报、误报或过度脱敏，纠正并确认后重新生成，检查纠正是否实际应用；再记录至少两项学校规则缺口。每组最后用一句话汇报一个关键发现和一个规则缺口。

### Memory 与跨会话验证
只明确保存抽象复核偏好，不把真实文件事实自动写入长期 Memory。可用的教学例子是“筛选结论标为待复核”。保存后新开会话，重新上传同一授权文件并核对实际条目引用、版本与输出行为；不能只凭快照存在或哈希变化声称已应用。
若课堂环境不支持跨会话持久化，明确说明限制。仅在讲师环境确实可验证时投屏展示，否则将该观察项记为未验证。Memory 只是候选上下文，不授予学校分类、组织身份或执行权限。

### 可选经营数据保护练习
每组使用讲师预置的 finance-briefing-sample-zh.pdf，输出敏感数据标注，并逐项回溯原文（lineage back to source）。每项标注应包含信息类别、敏感原因、保护建议、源文件名、页码和原文片段；重点检查供应商与采购信息、欠费金额与学段的组合推断、现金流预测及扩校计划，避免将预测写成已确认事实。
让学员至少选择两项标注，沿来源引用返回 PDF 对应位置核对准确性、漏报与过度标注。自动定位不可用时，人工打开原件对照并记录产品定位未验证，不编造页码或引用。无需分配有权限／无权限账号，不安排申请查看或财务负责人批准／拒绝，不执行旧 workshop_finance_review 审批流程；本练习不计为报销政策 Demo 完成。讲师单次演示不超过 5 分钟，由助教举牌提醒，到点切学员操作，未完成部分由各组继续核对。

### 故障处理与课后动作
上传或解析失败：换预置可解析样本；单组问题尽快转助教处理，保持其他组进度。功能未就绪：说明未验证项与实际限制，不虚构成功。进度超前：要求再找一条证据缺口或组合风险，避免添加新 Demo。
课堂结束后按客户约定删除上传文件、中间文本、缓存和临时报告。作业在 5 个工作日内由讲师书面反馈，至少给出一个优点、一个主要风险和一个修改建议。八字段 Eval 只检查结构与非空，不证明发现正确或学习达标。
